# python-bioinformatics-learning

My journey learning Python and applying it to bioinformatics.

## Python Practice

Small Python exercises and experiments.

## Projects

### Number Guessing Game

An interactive command-line game that selects a random number from 1 to 100. The player has seven attempts and receives feedback after each guess.

Run it with:

```bash
python3 "Number Guessing Game.py"
```

### Climate Simulation

An early placeholder for a climate simulation project. It currently prints a basic greeting and is ready for future development.

Run it with:

```bash
python3 climate_simulation.py
```

## Requirements

- Python 3.8 or newer

The projects use only Python's standard library; no package installation is required.

## Security

Local secrets, credentials, private keys, virtual environments, and Python cache files are excluded through `.gitignore`. Do not place sensitive values directly in tracked source files.
